# Federated Catalogue Applications

## federated-catalogue-rest-server

This app hosts catalogue functionality behind HTTP endpoints so datasets can be managed and queried by other systems through a deployable server runtime. It is suited to operational environments that need configurable service behaviour, protocol-aligned responses and clear deployment guidance.
